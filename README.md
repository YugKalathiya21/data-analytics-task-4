# 📊 E-Commerce Sales Dashboard

## 📌 Project Overview

This project focuses on analyzing and visualizing e-commerce sales data using Microsoft Power BI. The dashboard provides valuable business insights through interactive visualizations, helping users understand sales performance, profit trends, and category-wise distribution.

---

## 🎯 Objective

The primary objective of this project is to transform raw sales data into meaningful visual insights and support data-driven decision-making.

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- E-Commerce Sales Dataset
- Data Visualization Techniques

---

## 📈 Dashboard Components

### 1. Sales by Category
A bar chart displaying total sales across different product categories.

### 2. Sales Distribution by Category
A pie chart showing the percentage contribution of each category to overall sales.

### 3. Profit by Category
A column chart comparing profit generated by different product categories.

### 4. Sales Trend Over Time
A line chart illustrating sales performance over time.

### 5. Category Slicer
An interactive filter allowing users to analyze specific categories.

---

## 🔍 Key Insights

- Technology category generated the highest sales.
- Technology category also produced the highest profit.
- Furniture and Office Supplies contributed significantly to overall revenue.
- Sales trends can be analyzed over different time periods.
- Interactive filters improve data exploration and reporting flexibility.
